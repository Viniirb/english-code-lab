# Login button does nothing on mobile browsers

## Steps to reproduce

1. Open the login page on a phone.
2. Type a valid email and password.
3. Tap the login button.

## Expected behavior

The app should log the user in and show the home page.

## Actual behavior

Nothing happens. The page stays the same and there is no error message.

## Environment

iPhone 13, Safari 17, app version 2.4.1.
