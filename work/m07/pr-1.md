# Add dark mode switch to the settings page

## What

This pull request adds a switch to the settings page. The user can choose the light or the dark theme.

## Why

Many users asked for a dark theme because they use the app at night.

## How to test

1. Open the settings page and turn on the dark mode switch.
2. Reload the page and check that the dark theme is still active.

## Notes

The choice is saved in the browser, so it is not shared between devices.
