# Explanations

## count_words
This function counts the words in a text. First, it splits the text into a list of words. Then it returns the length of that list. If the text is empty, the result is zero.

## is_even
This function checks if a number is even. It takes the number and divides it by two. If the rest of the division is zero, it returns true. Otherwise it returns false.

## find_longest
This function finds the longest name in a list. First, it starts with an empty text called longest. Then it looks at each name. When a name is longer than the current one, it saves that name. Finally, it returns the longest name.
