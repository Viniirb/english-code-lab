# Evidence

My first contribution is an issue in an open source project that I use every week:
https://github.com/example-org/example-project/issues/123

I opened an issue about a broken link in the documentation. First, I read the contributing guide, because I did not want to break any rule. Then I searched the old issues, and I did not find the same problem. I wrote the title and the steps to see the broken link, and I added the page address. The hardest part was to write a short and polite message without a translator. I read it three times and I fixed two small mistakes. A maintainer answered after one day and said thanks. Next, I want to send a small pull request to fix the link myself. I learned that a clear message is useful for people in every country, and that maintainers are happy when the report is easy to read.
