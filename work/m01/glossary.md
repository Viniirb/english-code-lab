# My glossary

## variable
pt: variável, um nome que guarda um valor
example: I change the variable when the user clicks the button.

## function
pt: função, um bloco de código que faz uma tarefa
example: This function checks if the email is valid.

## loop
pt: laço, código que se repete
example: The loop runs ten times and prints each name.

## array
pt: lista ordenada de valores
example: I keep all the user names in an array.

## string
pt: texto entre aspas
example: The name is a string, not a number.

## number
pt: número
example: The app shows the number of new messages.

## boolean
pt: valor verdadeiro ou falso
example: A boolean can only be true or false.

## object
pt: objeto, um grupo de valores com nome
example: The object has a name and an email.

## class
pt: classe, um molde para criar objetos
example: We create a new class for every type of user.

## method
pt: método, função dentro de uma classe
example: I call the save method after each change.

## parameter
pt: parâmetro, nome de uma entrada da função
example: The function has one parameter called name.

## argument
pt: argumento, valor real passado à função
example: I pass the file path as an argument.

## return
pt: retornar, devolver um valor
example: The function will return zero if the list is empty.

## condition
pt: condição, um teste verdadeiro ou falso
example: The condition is false, so the code does not run.

## error
pt: erro, problema que para o programa
example: The app shows an error when the password is wrong.

## bug
pt: defeito no código
example: I found a bug in the login page today.

## fix
pt: corrigir
example: I will fix the bug before lunch.

## test
pt: teste, código que verifica outro código
example: Every new feature needs a test.

## build
pt: compilar ou gerar o programa
example: The build fails when a file is missing.

## deploy
pt: publicar o programa para os usuários
example: We deploy the app every Friday afternoon.

## commit
pt: alteração salva no git
example: I make a small commit after each step.

## branch
pt: ramificação de trabalho no git
example: I created a new branch for this task.

## merge
pt: juntar duas branches
example: We can merge the branch after the review.

## review
pt: revisão de código
example: My teammate will review my code tomorrow.

## request
pt: requisição ao servidor
example: The app sends a request to the server.

## response
pt: resposta do servidor
example: The response has the data in JSON format.

## server
pt: servidor
example: The server is slow when many users arrive.

## client
pt: cliente, quem pede dados
example: The client shows the list on the screen.

## database
pt: banco de dados
example: The database keeps all the orders.

## file
pt: arquivo
example: I saved the result in a file.
