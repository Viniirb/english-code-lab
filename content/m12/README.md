# Module 12: A short technical article

Write `work/m12/article.md` (300 to 500 words) about something you learned while coding. Structure:

```markdown
# Title

Short introduction (what problem, why it matters)

## The problem
## The solution
(include one code block)
## What I learned
## Conclusion
```

Rules: at least 4 `##` headings (one is `## Conclusion`), at least one code block, simple sentences
(reading level ≤ 11), few spelling mistakes. Read it aloud once: if you run out of breath, split the sentence.
