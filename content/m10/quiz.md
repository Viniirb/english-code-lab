# Cloze: phrasal verbs in tech

Choose the best option for the blank. Answers in `work/m10/answers.txt`.

**q1.** We need to ___ the old code before the release.

- a) get rid of
- b) get on with
- c) get along with

**q2.** The new version has a bug, so we will ___ to the last version.

- a) roll over
- b) roll back
- c) roll in

**q3.** Can you ___ why the test fails?

- a) figure in
- b) figure on
- c) figure out

**q4.** I will ___ the new server this afternoon.

- a) set up
- b) set off
- c) set aside

**q5.** Please ___ this problem and tell me the cause.

- a) look up to
- b) look into
- c) look forward

**q6.** We ___ the big task into small steps.

- a) broke down
- b) broke in
- c) broke up with

**q7.** Remember to ___ your files before the update.

- a) back off
- b) back down
- c) back up

**q8.** The team will ___ a security check next week.

- a) carry out
- b) carry on
- c) carry over

**q9.** Please ___ the temporary files when you finish.

- a) clean out of
- b) clean up
- c) clean off to

**q10.** The build ___ because of a missing file.

- a) failed
- b) fell
- c) fought

**q11.** Use this command to ___ the latest changes.

- a) pull away
- b) pull over
- c) pull down

**q12.** I am ___ for the new feature, so I check the pages every day.

- a) looking after
- b) looking forward
- c) looking for out
