# Module 10: Phrasal verbs in tech

A phrasal verb is a verb plus a small word, and it has its own meaning ("roll back" is not "roll" + "back").

1. Do the cloze in `content/m10/quiz.md`. Answers in `work/m10/answers.txt`.
2. Write 8 sentences in `work/m10/sentences.md`, one for each verb in `content/m10/verbs.json`, with this format:

```
roll back | We rolled back the release because the login was broken.
```
Each sentence needs at least 6 words and must use the verb (any form: roll back, rolled back, rolling back).
