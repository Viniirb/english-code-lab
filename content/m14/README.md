# Module 14: Capstone (open source + 14-day streak)

1. **Real contribution.** Find an open source project you use. Open an **issue** (a clear bug report or question) or a small
   **pull request** (a typo, a docs fix, a test) **in English**. Paste the link in `work/m14/evidence.md`, followed by a
   reflection of at least 120 words in English: what you did, what was hard, what you will do next.
2. **Streak.** Write a journal entry every day for 14 days in a row: `journal/YYYY-MM-DD.md`, at least 25 words each, in English.
   Topic: what you coded or read today. (If you miss a day, the streak starts again.)

Run `python scripts/validate_module.py 14` to check both.
