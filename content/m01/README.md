# Module 01: Developer vocabulary

Create `work/m01/glossary.md` with at least 25 entries from `content/m01/terms.md`. Use exactly this format:

```markdown
## variable
pt: variável, um nome que guarda um valor
example: I change the variable when the user clicks the button.
```

Rules:
- The word in the heading must be one of the target words.
- `pt:` is your meaning in Portuguese (your own words).
- `example:` is an English sentence YOU write (at least 4 words) that uses the word. Do not copy the definition.

Then train with `python scripts/srs.py review`.
