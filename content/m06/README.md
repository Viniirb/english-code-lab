# Module 06: Bug reports

Write a bug report for each bug in `content/m06/scenarios.md`: `work/m06/bug-1.md`, `bug-2.md`, `bug-3.md`.
Copy the structure from `content/m06/TEMPLATE.md`. A good report lets a stranger reproduce the problem in one minute.

- Title: what is broken and where. Not "It does not work".
- Steps: numbered, small, in order (at least 3).
- Expected vs actual: one or two clear sentences each. Invent realistic details for the environment.
