# Module 02: Reading error messages

1. Read `content/m02/errors.md`.
2. Take the quiz in `content/m02/quiz.md`. Write your answers in `work/m02/answers.txt`, one per line (`q1: b`).
3. Write `work/m02/explanations.md`: one section per error (`## E1` ... `## E8`). In each section explain in
   your own English what the problem is and one thing to try. Use 8 words or more per error.

Tip: do not translate the whole message word by word. Find the **noun** (what) and the **verb** (what happened).
