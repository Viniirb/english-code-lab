# Quiz: error messages

Choose the best meaning. Answer in `work/m02/answers.txt` like `q1: b`.

**q1.** What does E1 mean?

- a) The internet is down.
- b) The code tries to read a field of a value that does not exist.
- c) The file name is too long.

**q2.** What does E2 mean?

- a) A symbol is in the wrong place in the code.
- b) A variable has a wrong color.
- c) The server is off.

**q3.** What does E3 mean?

- a) The package has a virus.
- b) The package is too big.
- c) A package that the code needs is not installed.

**q4.** What does E4 mean?

- a) The password is wrong.
- b) The program tried to connect, but nothing is listening on that port.
- c) The disk is full.

**q5.** What does E5 mean?

- a) The file is not at the path you gave.
- b) The file is too large.
- c) The file has a virus.

**q6.** What does E6 mean?

- a) The list is empty on purpose.
- b) The list has the wrong type.
- c) You asked for an item at a position that the list does not have.

**q7.** What does E7 mean?

- a) You ran a git command outside a git project.
- b) Git is not installed.
- c) Your branch is old.

**q8.** What does E8 mean?

- a) Your commit message is too long.
- b) Git could not send your changes to the remote repository.
- c) Your computer has no disk space.
