# Module 07: Pull request descriptions

Write a description for each pull request in `content/m07/scenarios.md`: `work/m07/pr-1.md` and `work/m07/pr-2.md`.
Use the structure of `content/m07/TEMPLATE.md`. A good description saves the reviewer time:

- **What**: the change, in 1 to 3 sentences.
- **Why**: the problem or the goal.
- **How to test**: at least 2 steps (numbered list or `- [ ]` items).
- **Notes**: risks, screenshots, follow-up work.
