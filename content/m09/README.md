# Module 09: Explaining code in English

Explain each function of `content/m09/functions.py` in `work/m09/explanations.md`.
Use one section per function (`## count_words`, `## is_even`, `## find_longest`).

Rules:
- 3 to 6 short sentences per function.
- Say what it does, what goes in, and what comes out.
- Use at least 2 connectors: first, then, next, after, finally, because, so, if, when, otherwise.
- Keep sentences simple (the validator checks the reading level).
