# Module 08: Code review (reading and writing)

1. Take the quiz in `content/m08/quiz.md`. Answers in `work/m08/answers.txt`.
2. Read the five snippets in `content/m08/snippets.md` and write one review comment for each in `work/m08/review.md`
   (`## S1` ... `## S5`, 8 to 60 words each).

Rules for good comments:
- Be kind and specific. **Criticize the code, not the person.** Ask questions: "Could we...?", "What do you think?".
- Use labels: `nit:` for small things, `suggestion:` for ideas, `question:` for doubts.
- Include at least one positive comment (S5 is a good one).
- Avoid harsh words: stupid, wrong, terrible, obviously, lazy.
