# Module 04: Commit messages

Write one commit message for each scenario in `content/m04/scenarios.md`. Put them in `work/m04/commits.txt`:

```
S1: feat: add login button to the home page
S2: fix: handle empty user name
```

Rules (from the Conventional Commits style):
- At most 72 characters. No period at the end.
- Start the subject with an **imperative verb**: `add`, `fix`, `remove`... (as if giving an order to the code). Not `added`, not `adding`.
- Use `type: subject` in at least 5 messages. Types: feat, fix, docs, style, refactor, perf, test, build, ci, chore.
- Mention the key thing from the scenario.
