# Module 03: Reading documentation

1. Read `content/m03/readme-sample.md`. Do not use a translator on the whole text. Underline the words you do not know, then look up only those.
2. Take the quiz in `content/m03/quiz.md`. Answers go in `work/m03/answers.txt`.
3. Write `work/m03/summary.md`: a summary of the README in 25 to 70 words, in your own words.
   Mention at least 3 key ideas (for example: library, notes, file, autosave, search, limit, issue).
