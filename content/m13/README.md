# Module 13: Interview answers (STAR)

STAR is a simple structure for answers about your past work: **S**ituation, **T**ask, **A**ction, **R**esult.

Write one answer for each question in `content/m13/questions.md` in `work/m13/answers.md`:

```markdown
## Q1
Situation: ...
Task: ...
Action: ...
Result: ... (with a number)
```

Rules: each label line has at least 12 words; each answer has at least 90 words; use "I" at least 5 times (say what YOU did);
the Result has a number (time, percent, users). Use true stories.
